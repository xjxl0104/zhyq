# 对标卡片：阿里云数字园区（AIoT 数字园区引擎 + DataV 大屏/数字孪生生态）

**资料充分度**：中——DataV/TwinFabric 官方文档充分、D3 维度可信度高；AIoT 数字园区引擎多个帮助页直接抓取已 404（仅能通过搜索索引快照多源交叉确认），产品线疑似收敛/停止维护，功能菜单树为据文档目录重建、非控制台实测；无公开 demo 或源码仓库佐证园区引擎后台形态。

## 定位与目标用户
阿里云的园区数字化不是一个 SaaS 成品，而是"引擎 + 生态"：AIoT 数字园区引擎面向集成商/ISV，通过物业管理一体机利旧接入门禁、摄像头、道闸、BA 等存量子系统，建立设备/人员/空间/告警/联动/工单等统一中心，供上层 SaaS 开发复用；DataV（Board/Atlas/Note/TwinFabric）则是通用低代码可视化与数字孪生搭建平台，承担园区 IOC 大屏与三维孪生展示。目标用户是园区集成商、ISV 和政企园区运营方，最终管理动作通过钉钉触达管理者。

## 功能菜单树 / 模块划分
- AIoT 数字园区引擎（控制台）
  - 园区概览（项目 appKey/appSecret、多项目按业态隔离：园区/小区/学校）
  - 空间管理（空间结构树、设备绑定到空间单元、空间资产可视化）
  - 设备管理（南向接入、设备运维、视频监控、品牌设备配置手册：海康/宇视/捷顺/立林/罗格朗等）
  - 人员管理 / 权限管理（子账号开通）
  - 告警中心 / 联动（AIoT 事件感知、联动规则）
  - 工单中心（事件驱动、统一推送）
  - 模板模型（园区设备物模型 + 子系统应用模型）
  - 应用管理（适配器应用、数据管理/AMQP 消息订阅、应用定义-部署-托管-分发）
  - 边缘侧（物业管理一体机、人车布控一体机：人员布控/车辆布控/消防通道占用、算法下发）
  - 行业能力（门服务：二维码/刷卡/蓝牙/人脸门禁；招商大数据：优商圈选/企业全息画像/企业图谱/风险监控；云边协同服务）
  - 开发者模式（OAuth 免登、数据模型/服务模型对接、告警规则开发、API 参考）
- DataV 可视化生态
  - DataV-Board 数据看板（400+ 组件、100+ 场景模板、拖拽画布、蓝图编辑器、7.0 新增可视化应用中心/演播厅）
  - DataV-Atlas 分析地图（时空数据 SQL 分析）
  - DataV-Note 智能分析（大模型驱动 Notebook 报告）
  - DataV-TwinFabric 数字孪生（孪生搭建、资源管理、孪生资产中心、工作空间、仿真）
  - 三维城市构建器 / 山海计划（AI 生成中国特色城市场景）
  - 发布分享（公开链接/密码/Token 验证、历史快照、演示投屏）

## 核心业务流程编排
1) 利旧接入流程（核心主线）：激活物业管理一体机 → 分发适配器应用和驱动到边缘 → 采集园区内网设备/子系统数据并上云 → 设备绑定到空间结构 → 云边互通（下行控制 + 上行感知闭环，门禁场景明确定义了"系统控制(下行)+业务感知(上行)"的业务闭环）。2) 事件-联动-工单闭环：平台统一感知车、人、周界、消防、能效、环境等多子系统的 AIoT 告警事件 → 事件中心建立统一事件模型 → 联动工单中心自动生成/派发 → 以统一事件推送能力精准推送到相关人员（钉钉触达），官方表述为"让相关人员直接面向事件操作，实现园区主动服务，减少重复性物业管理工作"。3) 边缘智能流程：算法下发到一体机做边缘计算（人员布控、车辆布控、消防通道占用识别）→ 产生智能化事件回流云端事件中心。4) SaaS 集成流程：园区 SaaS 通过 OAuth 免登接入，通过 AMQP 订阅事件模型（如 iotx_campus_space_device_change_event 空间设备绑定变化消息）实现数据联动，而非轮询。5) 大屏侧编排：DataV 蓝图编辑器以"事件→逻辑节点→动作"连线编排交互，逻辑节点含条件判断(If-Else)、多路判断(Case-When)、数据过滤器、计时器、WebSocket 屏间通信节点（支持大屏与移动端/触摸屏多端联动）。注意：园区引擎本身没有通用审批流引擎，流程编排集中在"设备事件→联动→工单"这条自动化链路上，行政审批类流程由钉钉/宜搭生态承接。

## 前端形态
调研重点维度 D3。DataV 是国内园区/城市 IOC 大屏的事实标杆之一：深色科技风、组件化拖拽画布 + 图层管理，编辑器与"蓝图编辑器"双画布（UI 布局与交互逻辑分离，逻辑用节点连线表达）。体验要点：(a) 400+ 可视化组件、100+ 场景模板，含官方设计套件（内置主题、设计规范、地图与标题素材），保证非设计师也能产出统一风格大屏；(b) 二三维一体：三维城市构建器支持商圈精模、实时阴影、大气效果、关键帧时间轴驱动二维图表与三维场景联动、多场景动态切换；TwinFabric 支持导入 GLB/GLTF 模型、倾斜摄影/BIM/点云/地下管线等多源数据（S3M 2.0 标准），IoT 点位绑定到 3D 对象实现"点击设备看实时参数"；(c) 交互编排低代码化：条件/多路/定时器/WebSocket 节点覆盖大多数大屏联动场景，7.0 还支持"对话生成交互事件"（AI 生成后可进蓝图编辑器查看修改）；(d) 发布体验：公开链接/密码/Token 三级访问控制、历史快照版本切换、演示投屏、跨屏 WebSocket 通信（大屏+触摸屏+移动端协同）；(e) 7.0 新增可视化应用中心与演播厅，把散屏收敛为"应用组合"。公开 demo：DataV 门户与模板市场 https://datav.aliyun.com/portal 可直接预览模板效果。园区引擎控制台本身则是阿里云标准控制台风（左侧树+表格），亮点不在后台 UI 而在大屏生态。第三方评测共识：智慧园区/城市场景下 DataV 的"3D 数字孪生 + 地理可视化 + SaaS 快速交付"组合优势明显，深度定制孪生项目上专业厂商（数字冰雹等）更强。

## 架构与功能设计要点
调研重点维度 D4。平台化架构呈"云-边-端 + 模型抽象 + 应用分发"三层特征：1) 模块边界：数字园区引擎把园区能力拆成独立"中心"——设备、人员、空间、边缘、告警、联动、工单，各中心提供统一数据服务模型，支撑车/人/周界/消防/能效/环境多子系统数据融合；空间树是贯穿性主数据（设备绑定空间、资产挂空间、孪生节点对应空间）。2) 扩展点/开放接口：核心抽象是"模板模型"——先定义园区设备物模型和子系统应用模型（如停车系统、门禁设备），厂商差异由"适配器应用"实现并可关联到模型，ISV 基于抽象模型开发 SaaS 而无需直连设备 API，实现"一次开发、多项目复用"；开放方式包括 OAuth 免登、REST API（设备管理/登录管理/人脸下发等）、AMQP 事件订阅。3) 应用生命周期平台化：面向 ISV 提供应用定义、部署、托管、分发全生命周期管理，应用可分发到其他项目的物业一体机——本质是一个园区应用市场/运行时。4) 多租户组织：以"项目"做资源管理与隔离，可按业态（园区/小区/学校）建多项目，官方强调集团可在一个平台上跨园区跨部门统一运营；DataV-TwinFabric 侧以"工作空间"隔离云资源、成员角色、项目数据与孪生资产，"孪生资产中心"支持跨应用/跨团队发布共享资产，资源以模型包/素材包/功能包三类"资源包"复用，功能包可扩展编辑态与运行态能力。5) 大屏集成安全：DataV 以 iframe 嵌入第三方系统，Token 验证采用 HMAC-SHA256 签名（_datav_time+_datav_signature 时效链接），并支持 datav_sign_ 前缀的 URL 参数签名校验防传参篡改。风险提示：园区引擎多个帮助文档页已 404、关联产品（物联网应用托管、数字社区平台等）标注"停止维护"，该产品线明显处于收敛期，架构思想可借鉴，产品本身不宜作为选型对象。无公开源码仓库，无目录结构可述。

## 可借鉴点 TOP5
- **[D3前端体验]** 把 /screen 大屏的组件联动从硬编码改为"事件→逻辑节点→动作"的声明式配置（参照 DataV 蓝图编辑器的条件判断/多路判断/定时器节点），用一份 JSON 描述"点击楼栋→过滤能耗曲线+告警列表"类联动，后续加联动不改代码
- **[D3前端体验]** 为 /screen 增加免登分享链路：生成带时效的 HMAC-SHA256 签名 URL（时间戳+签名两个 query 参数，服务端校验过期与篡改），大屏可直接投放园区展厅/招商接待屏而不暴露后台登录态；带业务参数时按 DataV 的 sign_ 前缀参数签名防篡改
- **[D4架构设计]** 第三方对接从"全模拟"升级为"标准模型+适配器"：为门禁、停车、能耗表计各定义一套标准数据模型+服务模型（上行事件/下行控制两向），厂商差异封装在独立适配器实现类里，业务与大屏只面向标准模型编程——补齐停车/门禁空白模块时先出模型接口再接真设备
- **[D2流程编排]** 建统一事件中心补联动短板：把 IoT 告警、能耗超标、投诉、合同到期等统一为事件模型，配置"事件→条件→动作"联动规则（自动生成物业工单+钉钉/企微推送指定责任人），复刻园区引擎"感知-事件-联动-工单"闭环，替代目前的简单状态流转
- **[D1功能分类]** 把空间树升格为全局主数据：楼宇/房源、IoT 设备、能耗点位、工单、租约统一挂到"园区-楼栋-楼层-房间"同一棵空间树（参照空间中心+空间资产可视化），大屏按空间下钻即可聚合展示该节点的租控/告警/能耗，顺带为将来资产管理模块预留载体
