# 对标卡片：明源云（不动产资管/云租赁/招商运营/天际PaaS开放平台）

**资料充分度**：中高：功能分类、D2流程、流程平台、设计体系均有官网产品页/开放平台/设计体系站点+发布会报道≥2源交叉佐证；但无公开可操作 demo，界面交互细节靠 Honeycomb 站点与应用市场截图推断，"回款2.5天""线索提升120%"等数字为厂商单方宣称，仅作参考。

## 定位与目标用户
明源云（0909.HK）是国内不动产生态链数字化头部厂商，从住宅开发 ERP 转型"投建营一体化"，存量业务主打云资管+云租赁+招商运营（数智园区3.0"招管运一体化"）。目标用户为央国企资产持有方、城投平台、产业园区/商业写字楼运营商（约250家国企平台公司在用资管运营产品，在管资产超1.9亿方）。底座为自研天际PaaS低代码开放平台，对标 Salesforce Lightning Platform。

## 核心业务流程编排
D2 主链路（招商→合同→账单→收款）编排是明源云最成熟的部分：(1) 招商前端：租控一张图+空置预警+到期预警作为"触发器"驱动招商动作（空置每日提醒、到期自动生成续租跟进），招商过程拆为"圈客-锁客-链客-拓客-接客-签客-挖客"七环节漏斗，系统沉淀跟进记录、历史洽谈报价、意向书文件，支持横向比价选商；招商代理/中介渠道分级评估纳入同一漏斗。(2) 合同环节：5大要素标准合同模版做条款管控，在线签约（电子化），签约即挂接计费方案——计费引擎覆盖10000+算费场景（含租金抽成等复杂计费），价格变动全程跟踪，合同变更/续租/退租走同一履约管理线。(3) 财务闭环被明确拆为"出账-催账-核账-做账"四段全在线流程：计费引擎按合同自动批量出账→一键催缴（联动小程序端租户缴费）→收款自动核销→开票→对接做账，官方宣称回款周期缩短至2.5天；支付侧通过应用市场接入微信/支付宝/银联及多家银行聚合支付。(4) 审批流不内嵌在业务模块里，而由天际流程平台（BPM）统一承接：零代码拖拽表单+可视化流程建模+仿真模拟上线前验证+参数化运维，对业务系统开放81个API接口和65个流程事件，支持集团-分公司-多业态的流程/数据/权限分级管控，并有IATQ流程效率分析工具找审批低效点。(5) IOC层：经营/管理/业务/执行四维指标体系按决策层→执行层分层下钻，L4级智能预警把风险处置做成"预警→任务→闭环"在线管理。

## 前端形态
有公开的企业级设计体系 Honeycomb Design（honeycomb.mingyuanyun.com，天际UED出品）：价值观"一致、灵活、高效、开放"，分四个域——Web Design（PC中后台）、Mobile Design（移动端）、Chart Design（数据可视化/大屏）、AI Design，提供 Vue 组件库（Honeycomb Design of Vue）和 React 脚手架，设计资源覆盖 Sketch/Figma/Axure，组件模式库沉淀"卡片列表""客户详情模板"等业务模式。导航/工作台范式：PC端"超级工作台"用默认部件+SOP部件拼装角色化首页，移动端"云助手"做千人千面数字门户；业务操作强调移动优先——租售"掌上一张图"、移动端租控。驾驶舱形态为"一屏一板一讯"三级体系：大屏（IOC/集团资管运营大屏，应用市场有现成模板）+ 管理看板（数见BI）+ 消息讯报推送，指标按决策层到执行层分层。C端触点是小程序租赁门户（找房/VR看房/签约/缴费）。无完全公开的可操作 demo，设计体系站点与应用市场截图为最接近的公开界面来源（honeycomb.mingyuanyun.com、appexchange.mingyuanyun.com/details/1285 集团资管运营大屏）。

## 架构与功能设计要点
非开源，无公开仓库（组件库托管内部 GitLab）。架构核心是"薄应用+厚平台"：所有 SaaS 业务（资管/租赁/招商/物业）构建在自研天际PaaS之上。平台分五大云/五大套装：开发云（aPaaS，元数据驱动+模型驱动低代码建模，对标 Salesforce Lightning，客户自助开发占比宣称95%）、集成云（iPaaS，对标 Mulesoft：接口中心/连接中心/事件中心/编排中心/模板中心，内置 SAP、Oracle、用友、金蝶、企业微信、钉钉连接器及 REST/WebService/TCP 协议连接器，接口中心统一鉴权基于 IdentityServer4）、流程套装（bpmPaaS 独立流程平台，81 API+65流程事件对业务开放）、数据套装（数见BI+数据资产管理）、超级工作台套装（BPA+Portal）。扩展点三层：应用市场 AppExchange 分发第三方应用/API服务/模板组件；低代码建模平台供客户IT"拖拉拽"改造ERP（"繁星计划"认证体系）；流程事件+API 供二开。多租户/多组织：面向集团-分公司-多业态的流程、数据、权限三线分级管控，支持标准流程模板向下复制。部署支持混合云/私有化容器（天际容器云），信创适配鲲鹏/麒麟。设计要点：业务预警（空置/到期/收缴）作为跨模块联动的统一机制，而非各模块自造提醒。

## 可借鉴点 TOP5
- **[D2流程编排]** 把财务闭环从"账单+收款"两步拆成明源式"出账-催账-核账-做账"四段流水线：合同审批通过后计费引擎批量出账，催缴生成任务并联动租户端缴费入口，收款按账单自动核销，落在 zhyq 财务模块新增"催缴任务列表+自动核销规则"两个子页。
- **[D2流程编排]** 用"预警驱动业务"串联模块：空置预警、合同到期预警、欠费预警统一成一套预警中心，每条预警可一键转招商跟进/续租商机/催缴任务，替代 zhyq 目前各模块孤立的状态展示。
- **[D2流程编排]** 招商CRM按"线索-商机-签约"漏斗重构，商机下沉淀跟进记录、历史报价、意向书附件并支持多客商横向比价，签约动作直接从商机带出房源与价格生成合同草稿，打通 zhyq 招商→合同的手工断点。
- **[D4架构设计]** 补审批流引擎时参考天际流程平台的最小形态：可视化流程设计器+表单绑定+对业务模块开放"流程事件"回调（如合同审批通过事件触发生成账单+锁房源），把 zhyq 现有硬编码状态流转改为事件订阅，避免每个模块各写一遍审批逻辑。
- **[D3前端体验]** 把 /screen 大屏升级为"一屏一板一讯"三级：大屏保留给决策层，各模块首页加角色化指标看板（决策层→执行层分层下钻），再加消息推送日报/预警讯，指标口径与大屏共用一套定义。
