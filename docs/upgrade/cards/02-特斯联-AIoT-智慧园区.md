# 对标卡片：特斯联 AIoT 智慧园区（TacOS / AI PARK）

**资料充分度**：中：架构（招股书五层）与驾驶舱/联动案例有官方+媒体多来源印证，可信；但特斯联为项目制解决方案商，无公开产品手册、帮助中心或可试用 demo，功能菜单树为多来源拼合还原（招商/物业细粒度功能存疑），多租户与设计体系无公开资料。

## 定位与目标用户
特斯联是"操作系统驱动"的公域 AIoT 解决方案商，以自研五层操作系统 TacOS 为底座，面向楼宇、社区、园区、城市（楼社园城+双碳）提供软硬一体的全栈解决方案，私有化部署单价数百万至千万元级。目标用户是政府、园区运营方、大型物业/楼宇业主，而非中小园区 SaaS 客户；AI PARK（重庆/武汉/德阳）是其自建自营的智慧园区样板与产品试炼场。截至 2025 年中产品已部署于全球 172 城逾 900 客户。

## 功能菜单树 / 模块划分
- TacOS 操作系统（五层产品架构，可整体或组件化部署）
  - 智算物联网 AnyIOT：传感器/控制器/边缘网关（100+ IoT 协议、双机热备）/一体机/机器人
  - 全域数字化 AnyDigit：IoT 平台（设备抽象/设备管理/安全认证/规则引擎）＋数字孪生平台
  - 通用智能体 AnyAI：大数据中台、小模型 AI 中台、大模型平台、领域大模型（含园区大模型）
  - 全场景应用 AnyAPP：楼宇/社区/园区/城市自研应用
  - 开发者平台 AnyStudio：全域数字化与智能体 API ＋ 智能魔方应用平台
- 园区业务应用（AI PARK / 产业园区解决方案，按五大产品线+运营应用拼合还原）
  - 安防：视频监控、安防机器人巡逻、"安消"一体化
  - 消防：火情监测、应急推演与疏散联动
  - 通行：人脸门禁、访客、可视对讲、梯控（人脸识别自动送达楼层）
  - 停车：AI 无人化停车场管理（车牌识别/远程对讲/中控）
  - 能源双碳：元启 OriginSYS 楼宇自控、Gaia ABAS 能源平台、天恒碳管理（能耗采集/碳足迹/光储直柔）
  - 楼宇运营（ABAS BI）：环境监测、设备优化运行、资产管理、人力/通行/停车运营数据汇聚
  - 智慧办公：智能会议室（自动纪要）、智慧照明/空调按人员密度调节
  - 机器人服务：物资递送、巡护、跨楼层自主通行
  - 产业运营：企业分布与发展态势展示（招商侧仅有展示层，未见招商 CRM/合同/账单类模块）
  - 数字孪生驾驶舱：园区全要素 3D 孪生大屏（CityOS 层直观呈现）
- 终端形态：管理端大屏/PC ＋ 企业/员工移动 App（远程控能耗、一键通行、远程开门）

## 核心业务流程编排
D2 重点。特斯联的编排能力分三层：(1) 规则层——AnyDigit 的 IoT 平台内置规则引擎，负责设备抽象后的告警、趋势、时间表策略；OriginSYS Ultra 把 Snap7/EtherCAT/Modbus 等多协议设备的"报警、趋势、时间表"收敛到同一平台集中处理，实现跨子系统（暖通/照明/消防/门禁）联动。(2) 调度层——TacOS 以"统一调度服务模块"把物联智控、AI 算法调度、GIS、流媒体等标准化服务统一接入，支撑跨楼宇/园区/城区的跨场景联动（官方称支持 20+ 业务堆叠、多级空间无缝链接）。(3) 智能层——近两年从静态规则演进为"模型+系统"路径：园区大模型学习使用习惯后驱动自动化（按空间人员密度调空调照明、按参会对象驱动会议系统、机器人辅助救援），强调"模型与规则融合、相互转化"。标杆联动案例：火灾应急流程——驾驶舱依据火情等级+各片区人员密度实时推演决策，自动向对应空间的通风/排气系统下发指令，并生成逃生路线引导疏散，是典型的"事件触发→态势推演→多系统协同动作→人员引导"闭环。能源侧联动：楼控系统响应电网峰谷/虚拟电厂聚合指令动态调节负荷（需求侧响应 DSR），并协同"舒适节能大模型"调节环境参数。注意：特斯联未公开面向管理员的可视化流程/审批编排器产品文档，其编排偏"设备与空间自动化"，不含租赁合同审批类业务流；这与 zhyq 缺审批流引擎的空白是两个方向。

## 前端形态
D3 重点。特斯联无公开可注册的线上 demo，可视化形态来自官方新闻与案例（多来源一致）：(1) 数字孪生驾驶舱大屏是其门面形态——对园区建筑、人、车等全要素 3D 孪生，能反映现实昼夜晴雨且可下钻到室内空间；关键差异在于大屏"可操作"：不同物理空间的设备可在同一屏幕上交互、联动、下发控制指令，而非只读展示（重庆 AI PARK 以"数据全融合、状态全可视、业务全可管、事件全可控"获数字孪生优秀案例）。(2) 大屏信息组织：安防态势、楼宇能源、智能会议室/电梯/照明等子系统运行状态、企业分布与发展态势（招商视角）多主题叠加在同一孪生底座上，三维模型同时承担安防/交通/环境/物业数据的走势呈现与趋势推演。(3) 管理端：OriginSYS Ultra 提供"快速组态"能力，用户可拖拽快速构建设备监控可视化界面，支持趋势跳转等操作——即楼控 SCADA 式的可配置监控页而非固定报表页。(4) 移动端：入驻企业/员工 App 可远程操控办公区能耗设备、查看实时能耗、一键通行/远程开门。整体设计语言为深色科技风三维大屏＋工控组态风管理端，未见 Element Plus 式表单后台的公开截图；无公开设计体系文档。参考链接：驾驶舱描述 https://www.chinanews.com.cn/cj/2023/06-02/10018357.shtml，武汉园区大屏 https://www.tslsmart.com/news/65603771bcb93/。

## 架构与功能设计要点
核心是 TacOS 五层模块化架构（招股书口径）：智算物联网 AnyIOT（传感/控制/云边端/机器人，物理层）→ 全域数字化 AnyDigit（IoT 平台＋数字孪生两大核心产品，含设备抽象、设备管理、安全认证、规则引擎）→ 通用智能体 AnyAI（大数据中台、小模型 AI 中台、大模型平台、领域大模型）→ 全场景应用 AnyAPP（楼/社/园/城自研应用）→ 开发者平台 AnyStudio（对外暴露全域数字化与智能体的 API＋"智能魔方"应用平台，为生态开发者提供扩展点，另有 Powered by TacOS 生态联合方案）。设计要点：分层解耦，"既能整体平台部署、又能子系统组件化模块化部署"，同一底座向上适配楼宇/社区/园区/城区多尺度场景，边缘网关承担协议归一（100+ 协议）与云边协同；扩展点集中在 AnyStudio 的 API 层和 IoT 平台的设备抽象层。产品发布会另有 CityIoT/CityOS/CityAI/CityApp/CityStudio 的同构表述。规模口径（官方宣称，未独立验证）：支持城市 3 级架构、20+ 业务堆叠、5+ 城市群联动。多租户组织方式无公开资料（项目制私有化部署为主）。无开源仓库，未发现 GitHub/Gitee 官方代码库，故无目录结构可考。楼宇孪生配套算法平台 Archi-Brain / 仿真平台 Archi-Sim 负责设备运维数据的预测与优化建议。

## 可借鉴点 TOP5
- **[D2流程编排]** 借鉴 TacOS 的 TCA 式设备场景联动：在 zhyq IoT 告警模块加"触发(设备事件)-条件(时段/阈值/空间)-动作(生成物业工单/通知租户/联动关停)"可配置规则表，把现在告警→人工处理的断点变成告警自动派单闭环
- **[D2流程编排]** 借鉴其火灾应急"事件→推演→多系统动作"编排：为 zhyq 预置 3-5 个跨模块联动模板（如能耗超限→自动生成节能工单+推送企业、设备离线→巡更任务自动加点），以模板库代替通用编排引擎，低成本先落地
- **[D3前端体验]** 把 /screen 从只读大屏升级为"可操作驾驶舱"：告警点位支持点击下钻查看设备详情并直接派单/确认，参照特斯联"状态全可视、事件全可控"——大屏挂上现有工单 API 即可，不需要 3D
- **[D3前端体验]** 借鉴其空间底座叠加多主题的做法：用楼层平面图/2.5D 楼宇剖面图做 zhyq 的空间视图，把租控状态、能耗热力、设备告警三类数据切换叠加在同一张图上，替代三个独立列表页，也是全 3D 孪生的低成本替代
- **[D4架构设计]** 借鉴 TacOS 分层中"IoT 平台(设备抽象+规则引擎)独立于应用层"：把 zhyq 的 IoT 设备/告警从业务模块中抽成独立设备接入层并定义标准设备模型与开放 API，为补齐停车、门禁模块及替换模拟对接预留统一接入位

## AI 备注（一行）
AI 嵌入位：园区领域大模型直接挂在自动化流程里（按空间人员密度调空调照明、会议系统自动生成纪要）；OriginSYS Ultra 新增空间智能体 Agent 助手，可对话式操作楼控——"模型+规则融合"是其编排层的 AI 位。
