## 4. 财务边界（重要设计约束）

用户明确要求不改财务/合同逻辑。三处涉及金额的新功能均遵守**只算只存、不写账单**原则：

- **#23 预订费**：BookingPolicy.calcFee 计算并存于 `rsv_booking.fee`，不写 fin_bill、不触发收款。
- **#21 停车费**：ParkingFeeCalculator 计算并存于 `acc_parking.fee`，前端带"试算金额，未计入账单"提示。
- **#20 资产价值**：`am_asset.price` 仅记录，不入账。

真要并入账单是后续工作，与 #11 催缴同批、需先审设计。
