# 系统管理与权限配置

系统管理按角色管理、用户管理、菜单管理、字典管理、运营资源、消息中心排列。部门管理、岗位管理退出导航和授权配置；旧页面链接分别跳转至用户管理和角色管理。

角色权限和用户额外授权共用 PermissionSelector，以 layout/menu.js 的 01–10 业务目录为唯一展示结构。页面访问与操作权限为独立的真实菜单 ID；展示目录使用虚拟 ID，不写入数据库。可整组选择、逐项调整、搜索并批量勾选搜索结果，切换目录不会丢失其他组的选择。角色继承权限单独标注，不因查看而复制为用户直接授权。

历史菜单目录记录不会自动展开成新增权限；预算、采购计划、物业检查等共享接口权限在所属业务目录明确标注共用操作。未识别的自定义权限仍在所属类别的其他功能中显示。我的建议默认开放，建议管理保持显式授权；已有显式授权不被自动撤销。权限数据读取失败时禁止保存，防止误清空。

V81 只停用部门、岗位相关菜单及权限并调整角色/用户菜单排序，不删除部门、岗位、用户关系、历史角色授权或数据范围。回退时需按上线前菜单状态恢复这两类记录；业务数据无需恢复。

验证：权限映射与真实 Element Plus 交互测试覆盖部分授权回显、跨组保留、搜索选择、目录批量选择和继承/默认权限；MySQL 8 验证停用范围、顺序、历史关联保留与重复执行。部署后通过公开 version.json 验证实际前端构建版本，并检查新的页面资源已包含权限选择器。
