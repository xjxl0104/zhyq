# 实现清单

## 一、应收明细登记表

- 新增共享导入批次和审计行，支持文件哈希防重、预览、绑定、确认、批次历史和回滚。
- 精确解析“应收明细登记表”标题及 27 列表头，读取公式缓存值并核对面积、金额和总计。
- 原始工作簿不落盘；账号显示值和账号公式从审计 JSON 中清理，完整账号只以 AES-GCM 密文保存。
- 新增应收登记、计费规则、保证金台账和收款账户数据结构。
- 免租、折扣、递增、每年最后一个月免租、租金抵扣和物业免缴转为可执行计费规则。
- 租金和物业费“抵扣”均使用 `OFFSET` 固定金额规则，不等同于整月免租。
- 绑定时验证租户、合同、合同房间和统一空间树的存在、园区归属及相互关系。
- 用租户、合同及房间/空间主数据生成稳定业务键；更正名称或签约期限不会复制登记表。
- 修订导入更新原登记并递增来源版本；更新前保存登记、规则和保证金快照。
- 已生成账单或已有保证金实收时拒绝工作簿直接覆盖。
- 旧批次已被新批次覆盖后，服务端拒绝撤销旧批次；合法撤销使用当前乐观锁版本恢复快照。
- 账单生成与撤销先锁定同一活动登记表行；撤销在锁内检查全部历史账单，并以批次号和版本条件软删除，关闭并发生成窗口。
- 手工新增/编辑采用白名单 DTO，状态、来源批次、来源版本、账户和租户隔离字段由服务端控制。
- 按月生成租金、物业费账单，并分别生成租金保证金和物业保证金账单；`billing_key` 只对活动账单唯一，保证幂等且允许多轮软删除。
- 前端提供 27 列登记表、筛选、详情、受控导入、四类主数据绑定、批次撤销、导出和按权限显示操作。

## 二、自动售货机

- 应用中心增加“自动售货机”入口和 `/app/vending` 本地经营工作台。
- 厂商入口强制 HTTPS，并通过 `noopener,noreferrer` 打开，不携带园区令牌。
- 新增机器、销售、补货、故障、对账五张本地副本表及五类标准 Excel 模板。
- 五类导入支持预览、错误行排除、防重、稳定业务键新增/更新、确认和持久化批次历史。
- 更新既有记录前保存旧值；撤销时恢复旧值，新插入记录则逻辑删除。
- 唯一索引改为“仅活动记录唯一”，允许多轮导入、撤销和再次导入。
- 服务端拒绝撤销已被后续批次覆盖的旧批次，防止覆盖或删除最新数据。
- 页面先读取当前用户能力，再分别加载查询、导入或厂商入口，拆分权限不会导致整页失败。

## 三、数据中心和运维

- 数据中心新增经营收入来源：租金/物业应收、租金/物业实收、售货机销售。
- 新增 V32/V33 Flyway 迁移、环境变量样例、Compose 配置、升级说明和 ver4.3 发布说明。
- 新增和扩展后端单元测试、权限测试、迁移契约测试、真实工作簿测试及前端 Vitest 测试。
- CodeGraph 已覆盖新增控制器、服务、实体、DTO、路由和测试代码。
