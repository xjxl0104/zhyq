# 云仓三维首页设计

用户要求：依据八张云仓照片，在现有 Vue 3 项目中制作可本地体验的 BIM 风格三维首页，点击模型关联园区、物业、合同、监控、消防模块。已明确授权先做本地可运行版本。

## 方案

使用 Three.js 程序化几何重建白色横向外墙、条带窗、青蓝转角、装卸口、屋顶机房。独立配置尺寸和 8 层示意结构；照片不足以核实尺寸、层数和现场设备坐标。不是测绘或 IFC 工程模型。

主界面采用白色导航、浅灰绿场景、青绿强调色，建筑为视觉中心。外观 / 分层 / 室内模式共用相机与模型；楼层选择、缩放、复位、自动环绕、业务图层、空间点位和详情面板均可操作。室内显示柱网、梁、风管、消防管网和分区。

## 代码边界

- `src/views/twin/twinData.js`：模型参数、楼层、业务点位、演示记录、真实路由映射。
- `src/views/twin/warehouseModel.js`：构造与更新模型，不依赖 Vue 或后端。
- `src/views/twin/WarehouseScene.vue`：WebGL、相机、射线选择、标签投影和资源释放。
- `src/views/twin/TwinHome.vue` + `twin.css`：工作台和本地业务预览交互。
- `src/views/twin/TwinIcon.vue`：统一线性图标。
- `/dashboard` 使用三维首页，原经营看板保留在 `/overview`。
- `/twin-preview` 及子模块仅开发模式注册，公开访问但不修改登录 token、守卫或请求拦截器；所有记录静态且标注演示。
- 正常登录首页的业务入口指向已有模块；不伪造数据库 ID，不把照片参数混入生产统计。

## 验收

生产构建、既有测试与新增交互测试通过；浏览器验证实际 WebGL 画面、楼层切换、室内模式、图层筛选、业务跳转、参考照片、窗口变化。渲染异常提供错误提示和重试，卸载后释放 RAF、事件、GPU 资源。照片仅复制到本地忽略目录以便对照，不自动上传。服务仅监听回环地址。
