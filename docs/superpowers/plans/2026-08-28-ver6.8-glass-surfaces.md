# ver6.8 毛玻璃上传与展示卡片 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan. Tasks use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 从已通过验收的 `ver6.7` 建立 `ver6.8`，实现可复用的亮色毛玻璃表面，覆盖全部六类上传入口，并克制地应用于工作台和应用中心的低密度展示卡片。

**Architecture:** `GlassSurface.vue` 只负责表面、光团、滤镜回退和默认插槽，不拥有上传状态或业务逻辑。六个上传入口继续使用原 `el-upload`、校验、API、文件列表和提交事件；工作台与应用中心只替换展示容器，不改变数据获取、点击和布局语义。`upload` 变体有低速旋转环境光，`card` 变体保持静态渐变以限制同时运行动画数量。

**Tech Stack:** Vue 3 `<script setup>`、Element Plus、SCSS、Vitest、Vue Test Utils、Vite。

**Spec:** `docs/superpowers/specs/2026-08-28-gooey-glass-versioned-ui-design.md` 的第 1–3、6–9 节。

**Global Constraints:** 必须从已验收且干净的 `ver6.7` 创建；不从原本地 `ver6.6` 搬运代码；不改上传 API、请求头、文件校验、权限或业务文案；不把毛玻璃扩散到 `.table-card`、`.search-bar`、编辑弹窗和高密度统计卡；不新增 Tailwind、React、GSAP 或其他运行时依赖。

  })

Create `frontend/src/components/GlassSurface.vue`:

```vue
<script setup>
defineOptions({ name: 'GlassSurface' })

defineProps({
  variant: {
    type: String,
    default: 'card',
    validator: (value) => ['upload', 'card'].includes(value),
  },
})
</script>

<template>
  <div class="glass-surface" :class="`glass-surface--${variant}`">
    <span class="glass-surface__glow" aria-hidden="true" />
    <span class="glass-surface__veil" aria-hidden="true" />
    <div class="glass-surface__content"><slot /></div>
  </div>
</template>
```

不在组件内加入按钮、上传状态、API、文件列表或业务文案。

- [ ] **Step 4: 实现亮色毛玻璃 CSS 与回退**

同文件 scoped style 的关键规则：

```scss
.glass-surface {
  position: relative;
  isolation: isolate;
  overflow: hidden;
  border: 1px solid rgb(255 255 255 / 72%);
  background: rgb(255 255 255 / 58%);
  box-shadow: 0 18px 46px rgb(78 70 120 / 12%);
  backdrop-filter: blur(18px) saturate(125%);
}
.glass-surface__glow,
.glass-surface__veil { position: absolute; inset: 0; pointer-events: none; }
.glass-surface__glow {
  inset: -45%;
  background: conic-gradient(from 20deg, rgb(124 58 237 / 20%), rgb(251 146 60 / 14%), rgb(99 102 241 / 18%), rgb(124 58 237 / 20%));
  transform: translateZ(0);
}
.glass-surface--upload .glass-surface__glow { animation: glass-orbit 18s linear infinite; }
.glass-surface--card .glass-surface__glow { opacity: .55; transform: rotate(-12deg); }
.glass-surface__content { position: relative; z-index: 1; }
@supports not ((backdrop-filter: blur(1px)) or (-webkit-backdrop-filter: blur(1px))) {
  .glass-surface { background: #f8f9ff; }
}
@media (prefers-reduced-motion: reduce) {
  .glass-surface__glow { animation: none !important; }
}
```

`upload` 与 `card` 使用不同圆角和内边距；动画只改变 `transform`。添加来源注释：视觉方向参考用户提供的 Uiverse.io / monkey_8812 示例，并已重构为项目亮色设计。
