# ver5.1 应收导入·预览确认式自动建档 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 应收导入预览时列出"表格有、系统没有"的租户/空间待建清单,用户确认后批量建租户(去重)+合成空间/房源并同步空间树、回填绑定,并允许合同留空(仅登记不生成账单)。

**Architecture:** 后端在 receivable 模块新增 `ReceivableProvisionService` + DTO + 两个控制器端点;放宽 `ReceivableBindingValidator` 与 `ReceivableImportService.bindRow` 的"合同必填"校验;`confirm`/账单生成对合同为空的登记跳过账单。前端在导入向导加"补建主数据"一步。

**Tech Stack:** Java 17 · Spring Boot 3.2.5 · MyBatis-Plus · MySQL8 · Flyway;前端 Vue3 · Element Plus · Pinia。构建:后端 `mvn`(在 backend/ 下,环境见 docs/memory/zhyq-build-env.md),前端 `pnpm`(frontend/)。

## Global Constraints

- 分支 `ver5.0`(= ver4.3 + 项目切换);本功能提交后作为 **ver5.1**。
- 后端包结构:controller 直接注入 mapper,复杂事务才加 service(建档属复杂事务,用 service)。
- **新增 entity/controller/mapper 前先查重类名**(Spring bean 按简名注册,重名启动失败):`find backend -name '*.java'|sed 's|.*/||'|sort|uniq -d`。
- 金额用 BigDecimal;状态流转条件更新;收款账户走既有 `FieldEncryptionService`(密钥须 Base64 32 字节,见 docs/memory 或 .env)。
- 租户去重键=清洗后 name;清洗**只剥行尾半角括号** `\([^)]*\)$`,**保留全角** `（）`。
- 合同可空:`fin_receivable_register.contract_id` DB 已可空;仅需放宽两处 Java 校验。合同空 → 登记入库但**不生成账单**。
- 建完 building/floor/room 必须依序 `spaceSyncService.sync("building"/"floor"/"room", id)`,否则绑定校验报"尚未同步到统一空间树"。
- 复用优先:同名租户(未删除)复用不新建;同名项目/楼栋/楼层/房间复用不新建。
- 权限:建档预览/执行复用 `finance:receivable:import` 权限。
- 无自动化测试传统 → 后端可加 JUnit(项目已有 receivable 测试),前端手动验收 + 现有 vitest 不破坏。
- 实机验证在运行中的 Docker 环境(http://localhost,admin/zhyq@2026)用真实工作簿端到端跑。

```java
public void validate(Long systemTenantId, ReceivableBindRequest request) {
    if (request == null || request.tenantRefId() == null
            || (request.spaceId() == null && request.roomId() == null)) {
        throw new BizException("请绑定租户及空间/房间");
    }
    BizTenant tenant = tenantMapper.selectById(request.tenantRefId());
    requireSameSystemTenant(tenant, systemTenantId, "租户不存在或不属于当前园区");

    Contract contract = null;
    if (request.contractId() != null) {
        contract = contractMapper.selectById(request.contractId());
        requireSameSystemTenant(contract, systemTenantId, "合同不存在或不属于当前园区");
        if (!Objects.equals(contract.getTenantRefId(), request.tenantRefId())) {
            throw new BizException("合同与所选租户不一致");
        }
    }

    SpaceNode selectedSpace = request.spaceId() == null ? null : spaceMapper.selectById(request.spaceId());
    if (request.spaceId() != null) {
        requireUsableSpace(selectedSpace, systemTenantId, "空间不存在、已停用或不属于当前园区");
    }
    if (request.roomId() != null) {
        validateRoom(systemTenantId, request, selectedSpace);
    } else if (contract != null) {
        validateProjectSpace(contract, selectedSpace, systemTenantId);
    }
    // 合同为空且仅绑定空间(无房间):跳过项目归属校验,允许登记
}
```

```java
package com.zhyq.park.receivable.service;

public final class TenantNameCleaner {
    private TenantNameCleaner() {}
    // 反复剥去行尾的半角括号后缀 (....);仅半角 ( ),不动全角 （ ）
    public static String clean(String raw) {
        if (raw == null) return null;
        String s = raw.trim();
        String prev;
        do {
            prev = s;
            s = s.replaceAll("\\([^()]*\\)\\s*$", "").trim();
        } while (!s.equals(prev));
        return s;
    }
}
```

- [ ] **Step 6: 实现 ReceivableProvisionService.preview**

读批次各行的原始解析数据(ImportRow 的 rawJson,含租户名列与楼层列),去重产出清单。项目名归一:含 "DIPARK"/"DI PARK" 的楼层串归到项目名 "DIPARK"。

```java
@Service
@RequiredArgsConstructor
public class ReceivableProvisionService {
    private final ImportRowMapper rowMapper;
    private final ObjectMapper objectMapper;
    private final BizTenantMapper tenantMapper;
    private final ProjectMapper projectMapper;
    private final BuildingMapper buildingMapper;
    private final FloorMapper floorMapper;
    private final RoomMapper roomMapper;
    private final SpaceSyncService spaceSyncService;

    private static final String SYNTHETIC_PROJECT = "DIPARK";
    private static final String SYNTHETIC_BUILDING = "DIPARK主楼";

    public ReceivableProvisionPreview preview(Long batchId) {
        List<ImportRow> rows = rowMapper.selectList(new LambdaQueryWrapper<ImportRow>()
                .eq(ImportRow::getBatchId, batchId).orderByAsc(ImportRow::getRowNo));
        Map<String, ReceivableProvisionPreview.TenantItem> tenantByClean = new LinkedHashMap<>();
        Map<String, ReceivableProvisionPreview.SpaceItem> spaceByRaw = new LinkedHashMap<>();
        for (ImportRow r : rows) {
            RowFields f = readRow(r);                 // 从 rawJson 取 租户名、楼层串
            if (f.tenantRaw != null && !f.tenantRaw.isBlank()) {
                String clean = TenantNameCleaner.clean(f.tenantRaw);
                tenantByClean.computeIfAbsent(clean, c -> {
                    BizTenant existing = findTenantByName(c);
                    return new ReceivableProvisionPreview.TenantItem(
                        f.tenantRaw, c, guessType(c),
                        existing == null ? null : existing.getId());
                });
            }
            if (f.floorRaw != null && !f.floorRaw.isBlank()) {
                spaceByRaw.computeIfAbsent(f.floorRaw, raw -> {
                    Long existingRoom = findRoomByRoomNo(raw);
                    return new ReceivableProvisionPreview.SpaceItem(
                        raw, SYNTHETIC_PROJECT, SYNTHETIC_BUILDING, raw, raw, existingRoom);
                });
            }
        }
        return new ReceivableProvisionPreview(batchId,
            new ArrayList<>(tenantByClean.values()), new ArrayList<>(spaceByRaw.values()));
    }
    // guessType: 含 公司/有限/企业/厂/中心/店/合作社 → 1 企业,否则 2 个人
    // findTenantByName / findRoomByRoomNo: LambdaQueryWrapper eq + deleted=0 取第一条
    // readRow: objectMapper 读 r.getRawJson() 定位租户列(第3列)与楼层列(第4列)
}
```
> `RowFields`/`readRow`/`findTenantByName`/`findRoomByRoomNo`/`guessType` 为本类私有辅助;rawJson 的列键以 `ReceivableWorkbookParser` 解析产物为准(参照 ImportRow 现有 rawJson 结构)。

- [ ] **Step 7: 实现 provision(建档 + 同步树 + 回填绑定)**

```java
@Transactional
public void provision(Long batchId, ReceivableProvisionRequest req) {
    // 1) 建/复用租户:按 finalName 去重
    Map<String, Long> tenantIdByRaw = new HashMap<>();
    Map<String, Long> tenantIdByClean = new HashMap<>();
    for (var d : req.tenants()) {
        String key = d.finalName();
        Long id = tenantIdByClean.get(key);
        if (id == null) {
            if (d.reuseTenantId() != null) id = d.reuseTenantId();
            else {
                BizTenant existing = findTenantByName(key);
                if (existing != null) id = existing.getId();
                else {
                    BizTenant t = new BizTenant();
                    t.setName(key);
                    t.setTenantType(d.tenantType() == null ? 1 : d.tenantType());
                    t.setStatus(1);
                    t.setCode("AUTO-T-" + System.currentTimeMillis() + "-" + tenantIdByClean.size());
                    tenantMapper.insert(t);
                    id = t.getId();
                }
            }
            tenantIdByClean.put(key, id);
        }
        tenantIdByRaw.put(d.rawName(), id);
    }
    // 2) 合成项目/楼栋(复用优先)
    Long projectId = ensureProject(SYNTHETIC_PROJECT);
    Long buildingId = ensureBuilding(projectId, SYNTHETIC_BUILDING);
    spaceSyncService.sync("project", projectId);
    spaceSyncService.sync("building", buildingId);
    // 3) 每个楼层串建/复用 floor+room,并同步空间树
    Map<String, Long> roomIdByRaw = new HashMap<>();
    for (var s : req.spaces()) {
        Long roomId = s.reuseRoomId();
        if (roomId == null) {
            Long floorId = ensureFloor(buildingId, projectId, s.rawFloor());
            spaceSyncService.sync("floor", floorId);
            roomId = ensureRoom(floorId, buildingId, projectId, s.rawFloor());
            spaceSyncService.sync("room", roomId);
        }
        roomIdByRaw.put(s.rawFloor(), roomId);
    }
    // 4) 回填各行 binding(写回 ImportRow.binding JSON:tenantRefId + roomId),行转 ROW_VALID
    backfillBindings(batchId, tenantIdByRaw, roomIdByRaw);
}
```
> `ensureProject/ensureBuilding/ensureFloor/ensureRoom`:按 name(+父 id)查重,存在复用否则 insert 必填字段(见设计 §4;room 需 `code`=AUTO-R-… 唯一、`roomNo`=楼层串、status=1)。`backfillBindings`:遍历该批次行,按行的租户名/楼层串查出 id,写入 ImportRow 的 binding 字段并置 `ROW_VALID`、清空 errorMessage(复用 bindRow 的写回逻辑或直接更新)。
