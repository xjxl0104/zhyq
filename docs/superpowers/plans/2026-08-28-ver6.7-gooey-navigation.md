Create `frontend/src/layout/__tests__/GooeyNav.spec.js`，使用 fake timers，并给激活项注入可控几何信息：

```js
const activeRect = { left: 12, top: 24, width: 180, height: 48, right: 192, bottom: 72 }
const rootRect = { left: 0, top: 0, width: 220, height: 500, right: 220, bottom: 500 }

const mountNav = (activePath = '/dashboard', reduced = false) => {
  window.matchMedia = vi.fn().mockReturnValue({
    matches: reduced,
    addEventListener: vi.fn(),
    removeEventListener: vi.fn(),
  })
  const wrapper = mount(GooeyNav, {
    props: { activePath },
    slots: {
      default: '<div class="el-menu"><div class="el-menu-item is-active">工作台</div></div>',
    },
  })
  wrapper.element.getBoundingClientRect = () => rootRect
  wrapper.find('.el-menu-item').element.getBoundingClientRect = () => activeRect
  window.dispatchEvent(new Event('resize'))
  return wrapper
}
```

覆盖以下行为：

1. 指示器变为可见，CSS 变量为 `--gooey-x: 12px`、`--gooey-y: 24px`、`--gooey-width: 180px`、`--gooey-height: 48px`。
2. 初次定位不产生粒子；`activePath` 更新后粒子数为 8 或更少。
3. 900ms 后粒子清空。
4. `prefers-reduced-motion` 下路由变化不产生粒子。
5. 卸载后 `ResizeObserver.disconnect`、监听器和定时器均已清理。
6. 找不到激活项时 `.gooey-nav--ready` 不存在，但插槽内容仍可见。

- [ ] **Step 3: 实现组件状态和测量生命周期**

Create `frontend/src/layout/GooeyNav.vue`，公共接口固定为：

```js
const props = defineProps({
  activePath: { type: String, required: true },
})
```

模板结构固定为：

```vue
<div ref="root" class="gooey-nav" :class="{ 'gooey-nav--ready': ready }">
  <div class="gooey-nav__effect" aria-hidden="true">
    <span class="gooey-nav__pill" />
    <span
      v-for="particle in particles"
      :key="particle.id"
      class="gooey-nav__particle"
      :style="particle.style"
    />
  </div>
  <div class="gooey-nav__content"><slot /></div>
</div>
```

实现细则：

- `measureActive({ burst })` 只查询 `.el-menu-item.is-active`。
- 用 `activeRect - rootRect` 计算坐标，写入根元素的四个 CSS 变量。
- 第一次成功测量将 `hasMeasured` 设为 true，但不生成粒子。
- 后续 `activePath` 变化，在 `nextTick` 和两个 `requestAnimationFrame` 后测量并生成最多 8 个粒子。
- `scroll` 监听挂在根内容容器并使用 capture，`resize` 监听挂在 window。
- 如果存在 `ResizeObserver`，同时观察根和当前激活项；不存在时仍可通过 route/scroll/resize 测量。
- 粒子对象只包含 id 与 CSS 自定义属性；900ms 定时移除。
- `onBeforeUnmount` 中取消 RAF、clearTimeout、disconnect，并移除全部事件监听。

- [ ] **Step 4: 实现 Gooey CSS、回退和减少动画**

在同一组件的 scoped style 中实现：

```scss
.gooey-nav { position: relative; }
.gooey-nav__effect {
  position: absolute;
  inset: 0;
  z-index: 0;
  pointer-events: none;
  overflow: hidden;
  filter: url('#gooey-nav-filter');
}
.gooey-nav__pill {
  position: absolute;
  left: var(--gooey-x);
  top: var(--gooey-y);
  width: var(--gooey-width);
  height: var(--gooey-height);
  border-radius: 14px;
  background: linear-gradient(135deg, var(--brand), #8b5cf6);
  transform: translateZ(0);
  transition: left 360ms cubic-bezier(.2,.8,.2,1), top 360ms cubic-bezier(.2,.8,.2,1), width 240ms ease, height 240ms ease;
}
.gooey-nav__content { position: relative; z-index: 1; }
```

在模板效果层内加入尺寸为 0 的内联 SVG filter（`feGaussianBlur` + `feColorMatrix`），并保证 `aria-hidden="true"`。粒子只动画 `transform` 与 `opacity`。使用 `@supports not (filter: blur(1px))` 隐藏粒子，并在 `@media (prefers-reduced-motion: reduce)` 中关闭 transition/animation。
