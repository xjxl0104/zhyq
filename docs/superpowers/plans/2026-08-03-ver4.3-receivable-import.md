# ver4.3 应收明细登记表与受控导入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 以用户提供的 Excel 为权威来源，在现有系统中新增可审计导入、完整应收登记表、复杂计费规则、分账账单和前端管理闭环。

**Architecture:** 新增 `importing` 共享导入边界和 `receivable` 业务边界；原始 Excel 行写入导入批次，确认后生成权威登记表和结构化规则，再由独立 `ReceivablePlanService` 生成现有 `fin_bill`。现有租户、空间、合同、收款、流水、收据和发票继续作为关联主数据与正式财务流水。

**Tech Stack:** Java 17、Spring Boot 3.2.5、MyBatis-Plus 3.5.7、MySQL 8、Flyway、Apache POI 5.2.5、JUnit 5/Mockito、Vue 3、Vite 5、Element Plus、Vitest、Vue Test Utils。

## Global Constraints

- 开发分支固定为 `ver4.3`，基线为已发布的 `ver4.2`。
- 租费业务以《物业租金及物业管理费基础资料).xlsx》为权威口径；系统适配 Excel，不删减 Excel 字段。
- 原始工作簿包含真实租户和银行账号，不得提交到 Git；测试工作簿必须在测试代码中生成并使用匿名数据。
- 首批验收必须识别 9 条记录，并核对计租面积 84,700、实际面积 72,501.6、分摊面积 12,198.4、月租金 1,214,450、月物业费 169,494、月合计 1,383,944、租金保证金 2,712,900、物业保证金 301,200。
- 合同租金总金额使用 `DECIMAL(20,6)`；面积使用 `DECIMAL(14,4)`；月度金额与保证金使用 `DECIMAL(16,2)`。
- 按日单价统一使用工作簿的 30 天月计费口径，不使用自然月实际天数。
- 月租金、月物业费和月合计是导入时的权威金额；结构化规则计算值只用于核对，不得静默覆盖。
- 协议编号允许为空或包含多个编号；只生成内部编号，不伪造展示协议编号。
- 自然语言备注原样保存，不自动形成正式收款；只有人工确认的金额写入 `fin_payment`/`fin_flow`。
- 完整银行账号使用 AES-GCM 加密；环境变量为 `ZHYQ_FIELD_ENCRYPTION_KEY`，同时兼容现有 `APP_ENCRYPTION_KEY`，未配置时禁止导入完整账号。
- 租费批次只要有业务行错误、主数据未绑定或总计不一致，就不得确认。
- 所有新增敏感操作必须使用 `@PreAuthorize` 与 `@OperationLog`。
- 本计划完成后运行 `codegraph sync`，保持后端代码索引同步。

```java
public final class ImportFileHasher {
    private ImportFileHasher() {}
    public static String sha256(byte[] bytes) {
        try {
            return HexFormat.of().formatHex(MessageDigest.getInstance("SHA-256").digest(bytes));
        } catch (NoSuchAlgorithmException e) {
            throw new IllegalStateException(e);
        }
    }
    public static String rowFingerprint(String bizType, List<String> keys) {
        StringBuilder value = new StringBuilder();
        append(value, bizType);
        for (String key : keys) append(value, key == null ? "" : key.trim());
        return sha256(value.toString().getBytes(StandardCharsets.UTF_8));
    }
    private static void append(StringBuilder out, String value) {
        out.append(value.length()).append(':').append(value).append('|');
    }
}
```

```java
@Transactional(rollbackFor = Exception.class)
public ReceivableGenerateResult generate(long registerId) {
    ReceivableRegister register = requireConfirmed(registerId);
    List<ReceivableRule> rules = ruleMapper.selectList(new LambdaQueryWrapper<ReceivableRule>()
            .eq(ReceivableRule::getRegisterId, registerId).orderByAsc(ReceivableRule::getPriority));
    List<Bill> candidates = buildPeriodBills(register, rules);
    int inserted = 0;
    for (Bill bill : candidates) {
        if (billMapper.selectCount(new LambdaQueryWrapper<Bill>()
                .eq(Bill::getBillingKey, bill.getBillingKey())) == 0) {
            billMapper.insert(bill);
            inserted++;
        }
    }
    return new ReceivableGenerateResult(candidates.size(), inserted, candidates.size() - inserted);
}
```
