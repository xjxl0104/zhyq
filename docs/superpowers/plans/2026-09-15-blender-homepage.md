# Blender 模型与原系统首页接入

用户要求本地制作可交互云仓，随后提出使用 Blender，并核对是否能进入原项目首页。

已检查 Vue 3、Three.js、路由登录守卫、Layout、项目 Store 和业务路由。Blender 5.2.1 安装于本机 Steam 库。

1. 将 /dashboard 放入原 Layout children，保留完整菜单、项目初始化/切换、退出登录；三维首页离开时释放 WebGL，原经营看板保留 /overview。
2. 以已有照片参照几何为底稿，在 Blender 中组织楼层/外壳/结构/室内/消防分组，添加稳定属性、细化材质和边缘；保存可编辑 .blend 并导出 GLB。
3. 网页加载实际 GLB，依据结构属性延续选层、展开、室内、点位交互。模型尺寸和点位仍为示意，不绑定虚构数据库 ID。
4. 验证导出的实际资产、路由边界、真实 Layout 的项目上下文、生产构建及浏览器效果。后端未运行时明确区分页面集成验证与真实业务联调。

初始阶段仅在本地验证。用户在效果验收后已授权上传至 main，发布包包括照片、Blender 源文件、生成脚本与网页模型；服务器部署另行处理。
