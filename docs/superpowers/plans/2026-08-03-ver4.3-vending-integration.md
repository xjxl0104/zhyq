# ver4.3 自动售货机入口与受控导入 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在没有厂商 API 的前提下，为自动售货机提供安全外部入口、五类标准模板、受控数据导入、本地查询和可撤销批次。

**Architecture:** 复用应收计划建立的 `sys_import_batch/sys_import_row`，新增独立 `vending` 业务边界和五张本地副本表。系统只导入用户手工取得的标准模板或已验证格式映射，不模拟登录、不抓取页面、不保存厂商凭据。

**Tech Stack:** Java 17、Spring Boot 3.2.5、MyBatis-Plus 3.5.7、MySQL 8、Flyway、Apache POI 5.2.5、JUnit 5/Mockito、Vue 3、Vite 5、Element Plus、Vitest。

## Global Constraints

- 必须先完成 `2026-08-03-ver4.3-receivable-import.md` 中的共享导入任务。
- 售货机厂商没有开放 API；禁止自动登录、验证码绕过、页面抓取、Cookie/密码保存和反向写回。
- 外部入口固定指向 `https://fanmaiji.top/index?isFrom=login`，通过配置返回给前端并在新窗口打开。
- 本版本只承诺系统标准模板；厂商原生导出文件在获得真实样例并通过测试前不得标记为已支持。
- 支持机器、销售、补货、故障、对账五类模板；每类必须有稳定业务键、表头校验、预览、去重、确认、错误排除和整批撤销。
- 售货机表与应收台账完全隔离，只共享导入批次并在未来报表层汇总。
- 所有 API 使用 `vending:*` 权限；导入、撤销、配置和打开外部系统写操作审计。
- 外部链接使用 `noopener,noreferrer`，不把智慧园区 token 放入 URL。

- [ ] **Step 3: Implement service dispatch by enum**

```java
@Transactional(rollbackFor = Exception.class)
public int confirm(long batchId) {
    ImportBatch batch = batchService.requirePending(batchId);
    VendingImportType type = VendingImportType.fromBizType(batch.getBizType());
    List<ImportRow> rows = rowMapper.selectByBatch(batchId);
    if (rows.stream().anyMatch(r -> "INVALID".equals(r.getStatus()))) {
        throw new BizException("仍有未排除的错误行");
    }
    int imported = switch (type) {
        case MACHINE -> upsertMachines(batchId, rows);
        case SALE -> upsertSales(batchId, rows);
        case RESTOCK -> upsertRestocks(batchId, rows);
        case FAULT -> upsertFaults(batchId, rows);
        case RECONCILIATION -> upsertReconciliations(batchId, rows);
    };
    batchService.markCompleted(batchId, imported);
    return imported;
}
```

Use database unique keys as the final concurrency guard. On duplicate-key race, re-query and update the same business key.
