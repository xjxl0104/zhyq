# 多项目切换 (ver5.0) — 本地验收清单

配套实现计划:`2026-08-03-multi-project-switch.md`(Task 5 手动验收)。
分支:`ver5.0`(= ver4.3 + 项目切换)。本清单需在本地跑起前后端 + MySQL 后逐条实测。

## 一、验收前置

- 至少存在 **2 个项目**(用于对比隔离)。若只有 1 个,先在「空间与资产 → 建筑 → 项目管理」新建第二个。
- 用有权限的账号登录(演示账号 `admin / zhyq@2026`)。
- 打开浏览器开发者工具的 **Network 面板** 核对请求参数。

## 二、验收项(逐条勾)

- [ ] **1 切换器出现**:登录后顶栏面包屑左侧出现项目下拉,默认选中列表首个(或上次选择)。
- [ ] **2 读隔离**:打开「建筑管理」等列表页,Network 里 `/api/building/building/page` 请求 query 带 `projectId=<当前项目>`,数据只属于该项目。
- [ ] **3 切换生效**:顶栏切到另一个项目 → 多标签(TagsView)被清、当前页重载、列表数据变为新项目;无旧项目数据残留。
- [ ] **4 持久化**:切到项目 B 后刷新浏览器(F5)→ 仍停在项目 B(localStorage `zhyq_project_id` 生效)。
- [ ] **5 写归属**:在当前项目下新增一条楼宇(不手填项目)→ 保存后该记录 `project_id` = 当前项目。查库:`SELECT id,name,project_id FROM biz_building ORDER BY id DESC LIMIT 1;`
- [ ] **6 排除清单**:Network 核对 `/api/building/project/list` 与 `/api/auth/*` 请求 **不带** `projectId`(否则项目下拉会自己把自己过滤掉)。
- [ ] **7 文件上传不受影响**:在带附件上传的页面(如合同新增)上传文件,成功;FormData 请求未被注入破坏。
- [ ] **8 删项目回退**:删掉当前选中项目 → 登出再登录 → 自动回退到列表首个,不报错、不白屏。
- [ ] **9 换账号不串**:登出(项目状态被 reset)→ 换另一账号登录 → 不残留上一账号的项目选择。
- [ ] **10 零项目兜底**(可选):项目列表为空时,切换器显示「暂无项目」,点击跳项目管理页,后台不白屏。
