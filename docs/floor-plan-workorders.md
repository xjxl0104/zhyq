# 楼层平面图与报修定位

## 使用方式

1. 建筑管理点击楼宇名称或“楼层平面图”，选择楼层后上传 JPG / PNG。单张不超过 20MB、5000 万像素；PDF/CAD 先导出图片。没有楼层时可按楼宇层数建立，已有楼层可新增地下层或其他楼层。
2. 新增或修改工单，在“楼层定位”选择楼宇、楼层。点击平面图放置红点，可放大后定位、清除点位，也可用方向键调整。切换楼宇或楼层会清除旧点位。
3. 没有平面图时仍可保存楼层和文字位置说明。工单详情显示楼宇、楼层，以及报修时的图纸和点位。
4. “直接拍照”在手机调用系统拍照入口，在电脑请求摄像头预览后拍摄。没有摄像头或拒绝授权时仍能选图、上传附件。关闭拍照窗口时释放摄像头。照片上传完成才可保存工单，附件关联失败会提示重试且不重复建单。

## 数据与权限

- 平面图使用 `sys_file` 的 `floor_plan` 类型，楼层 ID 为业务关联；每次上传保留一个新版本。普通附件上传/删除接口不能改动这些图纸，避免破坏历史工单。
- V79 仅新增工单的楼层、图纸文件 ID、0–1 相对坐标及索引，不改写历史工单。
- V80 新增“楼层平面图-查看/上传”权限，继承现有建筑管理页面的明确授权及管理员角色。工单附件查询/编辑权限可读取图纸。
- 工单校验楼宇、楼层、图纸的园区/运营主体归属及坐标范围。编辑工单未操作定位时保留旧定位；主动更换定位时清除原房源和空间关联，防止旧房源与新楼层冲突。
- 上线前须核对生产 Flyway 版本；此环境尚无生产 SSH 密钥，无法查看生产迁移记录及自动部署日志。仓库当前最高版本为 V78。

## 验证

覆盖图纸真实格式校验、图纸归属与坐标边界、历史图纸版本保留、切换楼宇清除点位、缩放后的相对坐标、相机关闭释放、照片先上传后关联及附件权限。

已在本地 MySQL 8 验证 V79/V80：旧工单保留、坐标保存与清除、仅指定角色/用户获得权限，权限迁移重复执行不产生重复授权。浏览器验证点击图纸与放大后点位保持一致。真机摄像头取景须在具有摄像头的终端允许权限后验收。
