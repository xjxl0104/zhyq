- 页面功能标题、折叠入口、配置弹窗和空状态统一使用“云仓发货量同步”。功能说明为“按客户和作业仓库同步每日发货票数，并核对数据。统计在次日生成。”
- 数据来源单独明确为“云山接口”，并保留共享连接不代表当前加盟云仓已接入的说明。此次仅调整展示文案，不更换接口提供方、`YUNSHAN_*` 配置、授权范围或同步逻辑。

- 发货票数查询与逐笔订单推送继续作为两种独立接入方式展示，不因名称统一而共用凭证、生成订单或改变业务数据。

## 2026-10-17 独立客户与本地作业仓库

- ERP 页面主入口改为“客户与作业仓库”：选择本系统客户，手动录入所属加盟云仓的实际作业仓库名称、地址，再保存关联。客户按 ID 独立保存；例如“超级棒棒猪”不会作为“广东泽浩棒棒猪”的别名。
- V93 仅新增 `crm_operation_warehouse` 和 `crm_customer_operation_warehouse` 两张表，不改写既有客户、外部映射或历史票数。作业仓库按加盟云仓归属，可供多个独立客户使用；重复建仓/关联由唯一约束拦截，关系停用后可重新启用。
- 本地建档不读取云山授权目录、不调用外部接口，也不产生发货量、订单或佣金。客户/加盟云仓删除时，同一事务停用相关本地关系，保留档案。

- 外部接口未提供该客户/仓库时，仍可完成本地建档，不能用其他客户授权代替。确有不同名称但属于同一主体的情况需先核实并统一客户名称，不再提供任意覆盖。

## 2026-10-16 名称与授权范围核查（历史方案，下述手动任意关联已取消）

- 云山是加盟云仓企业，页面功能统一称为“发货量同步”，并单独标明数据来源为云山云仓提供的接口；业务字段使用“客户（货主）”与“作业仓库”，避免把客户与货主拆成两个主体，也避免将加盟企业与系统内仓库混为一谈。新增操作改为“客户关联”。
- 当前使用一组服务器级 YUNSHAN 应用配置，货主目录不随页面所选加盟云仓切换。货主接口不附加园区客户筛选；仓库接口按所选 parentOwnerNo 过滤；前端读取全部授权分页，代码没有将选项限定为某个公司或仓库名称。
- 客户主入口搜索园区正式客户，不按接口授权数量过滤。系统优先沿用该客户此前确认的接口编号；没有既有编号时，仅按完整同名记录给出候选，保存前核对。同名多条或未找到时不猜测，展开接口关联后人工核对；已有编号撤权后不自动替换成同名的新编号。只有一个可用作业仓库时自动带出，多个时选择。页面显示实际接口授权数量并支持重新读取；刷新时重新核验客户对应关系，不保留失效选项。
- 数据库唯一约束针对接口“货主＋作业仓库”组合，一个组合只能有一条园区客户与加盟云仓的关联；同一个园区客户可以对应多个组合。停用保留记录，不能借新建重复组合绕过。

## 业务范围

园区推荐客户到云仓，试点客户「棒棒猪」。本轮保存 **货主 × 仓库 × 日期 → 发货票数**，支持历史补拉和月度对账；不获取联系方式、订单明细、商品或重量。

此前确认的计佣口径为 **P4 每单定价 × 票数**，沿用 `docs/marketing/P4客户每单定价.md`。本轮不创建佣金、账单或汇总订单；真实数据和修正口径确认后再处理入账。

界面位于「全民营销 › ERP 对接」现有页面的「云仓发货量同步」区块，不新增菜单或路由。查询使用 `crm:marketing:erp:query`，映射配置和补拉使用 `crm:marketing:erp:config`。与原有 ERP 订单推送凭证分别展示。

## 数据校验和对账语义

- 日期按上海时间解释，`开始 ≤ 结束 ≤ 今天`，区间含首尾，最多 92 天。
- daily 拉完全部页后，必须满足日期范围正确、无重复日期、整数非负、快照元数据一致、记录数完整、逐日合计等于 `totalConsignNum`，然后才写入。
- 同一映射同步串行，保存阶段重新检查映射状态与关联主体；所有每日写入和成功日志同一事务。失败回滚后独立记录失败日志，手动操作向页面返回错误。
- 已有票数发生变化时累计 `revised_count`，保存 `last_revised_at`，原始 `first_consign_num` 不变。
- 云山未返回的本地日期只计入日志 `daysMissing`，不删除、不清零。
- `NO_STAT_DATA` 表示无统计，不能解释成实际零发货；真正零票需要存在对应日期行。
- 对账读取本地、summary、完整 daily，不修改数据库；差异包含本地缺失、云山缺失、票数不同。`summaryMatchesDaily=false` 表示两次远端查询的合计、数据状态或统计时间不一致，应重试；无统计时不宣称对账一致。
- 本地票数列表的合计覆盖整个区间，不受显示分页影响；其 `daysMissing` 是整个区间中本地无快照的天数，与同步日志的缺失定义不同。

## 配置与真实联调

仅由服务器环境变量提供凭证，不写入源码、文档或业务日志：

| 环境变量 | 用途 |
|---|---|
| `YUNSHAN_BASE_URL` | UAT `https://qcy-uat.yskc.cn/api`；生产 `https://qcy.yskc.cn/api`，须对方开放后使用 |
| `YUNSHAN_APP_ID` | 云山分配的外部应用编码 |
| `YUNSHAN_PUBLIC_KEY` | 云山 RSA X.509 公钥，PEM 或纯 Base64 |
| `YUNSHAN_SYNC_DAYS` | 每日回拉天数，默认 7，允许 1–92 |

三个外部接口为 `/v1/external/entity/owners`、`/v1/external/entity/warehouses`、`/v1/external/stockout/volume/query`。签名只包含实际发送的 Query 参数，所有值为字符串；固定样例规范化 JSON `{"endDate":"2026-10-02","queryType":"daily","startDate":"2026-10-01"}` 的 MD5 为 `d58346c866cfc350725565f07f9a9fec`。

新增映射在服务器端重新读取授权目录，验证货主、仓库组合并保存目录名称，不相信前端自由填写的名称。云山侧仍需在 `/setting/thirdPartApp` 授予本应用棒棒猪的正确组合；目录和业务接口返回的授权错误会展示出来。

真实联调还需要云山提供：

1. 已部署的 UAT 接口、appId 和公钥，并完成试点实体组合授权。
2. 确认 RSA 填充为 PKCS#1 v1.5、Base64 为标准编码；目前实现按该约定 mock 验证。
3. 确认历史 `consignNum` 是否会修正、修正窗口多久。它表示出库订单 COUNT(*)，不是商品件数或去重面单数。
4. 用真实授权范围核验 daily 全页合计与 summary，覆盖无统计、真实零票、缺失日期、撤权和映射歧义。
