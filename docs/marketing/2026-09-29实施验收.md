# 全民营销与智慧园区修改记录

本次按会议记录及后续确认实现：**P4 有定价权，P1–P4 的金额均自定义**。保留现有小程序与智慧园区后台的布局和独立云仓入口。

## 已实现

| 范围 | 修改结果 |
| --- | --- |
| 小程序入口 | 伙伴相关入口统一为“全民营销”。 |
| 注册与邀请 | 新伙伴注册必须提供有效上级邀请码并绑定邀请关系；新用户默认 P1。已有用户正常登录，云仓注册沿用原流程。 |
| 角色与称号 | P4 可在邀请体系内手动设置成员 P1–P4；后台可维护称号及客户锁定上限。自动晋降级停用。 |
| 客户定价 | P4 按客户／品牌填写总佣金、本人金额、最多两位其他受益人的金额；可不分配。所有金额支持 0.001 元，无固定比例或默认金额。 |
| 公司金额 | 公司保留 = 总佣金 − P4 本人金额 − 其他受益人金额；公司部分不会计入个人钱包。 |
| 智慧园区后台 | 客户页查看归属 P4、云仓和完整分配；计佣订单区分总佣金、伙伴金额与公司金额；收益明细展示新单价公式并区分历史规则。 |
| 计佣 | 唯一出库单号计一单；改价追加版本，只影响新入账订单。缺少定价的新单明确报错，补配置后可重试；重复导入不重复计佣。 |
| 金额与提现 | 佣金保留三位小数，现金申请精确到分，部分提现保留不足一分余额；原始佣金不拆改，退款仍按原权益扣回。 |

## 保留待明确的业务规则

积分换算、礼品清单、兑换及核销规则尚未确定，因此现有收益和现金提现继续保留。没有把会议举例写成固定兑换比例，也没有生成虚构的礼品兑换流程。

角色沿用现有 P1–P4 名称；最近的 P4 负责其来源客户，变更负责 P4 后需要重新配置价格。现有租赁计佣与云仓直签业务沿用独立规则。
