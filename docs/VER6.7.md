# ver6.7 发布说明

## 基线

- 上游基线：远端 `ver6.6` 提交 `a5b419827605efcc76fcc46fc4d87f3444aeb5b0`
- 本版本不包含原本地 `ver6.6` 工作树中的未提交改动。

## 界面调整

- 删除 TagsView 及其 Pinia store，页面导航回归侧栏、路由和浏览器历史。
- 项目切换器移动到顶栏右侧，并位于“监控大屏”入口之前。
- 删除 AI 助手占位入口和暗色切换功能。
- 启动时清除旧的 `zhyq_dark` 偏好和根节点 `.dark` 类；ECharts 统一使用亮色调色板。
- 左侧菜单保留原 Element Plus 多级结构，并增加 Vue 原生 Gooey 叶子选中效果。

## Gooey 行为与降级

- 初次进入仅显示静态选中胶囊，后续路由变化最多生成 8 个短暂粒子。
- 路由变化、菜单滚动、展开过渡、侧栏宽度及窗口尺寸变化后重新测量激活叶子。
- 效果层不接收指针事件，不复制菜单文字，不改变键盘和路由语义。
- `prefers-reduced-motion: reduce` 下禁用粒子与空间过渡，保留静态选中反馈。
- 无法测量或滤镜不可用时保留原静态靛蓝选中样式。

## 兼容性

- 无后端、数据库、权限、路由结构或上传行为变更。
- 独立监控大屏视觉不受亮色主题清理影响。

## 验证命令

```bash
cd frontend
pnpm test -- --run
pnpm build
```
