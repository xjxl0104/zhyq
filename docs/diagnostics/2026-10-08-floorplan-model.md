# 楼层图纸模型核对

基线：origin/main 78329b8，阿里云 /opt/zhyq 同 SHA。仅 SELECT 查询图纸与定位元数据，原图私存本机 tmp/floorplan-spatial-model，未提交图纸或写入生产数据。

源图为主楼（projectId=3，buildingId=5）2025.10 JS-1-0301～0308，当前文件 ID 66～73；旧文件 65 错绑地下室且不是当前图，不能套用坐标。图纸是建筑平面图 JPG，墙厚、门高、栏杆高、竖向梯段及消防设备精确位置不够完整，模型几何对应建筑图纸，不宣称竣工测绘级精度。主轴线 160m×72m，柱距 12 / 12.5m，H/G 双轴间距 0.28m。地上层标高 0/12/21.5/28.1/34.7/41.3/47.9m；七层层高仍采用原招商资料 6.6m。

坐标：Q/7 原点，向 A 为 +x，向 1轴为 +z；所有楼层局部几何以米建模，统一 sceneScale=.6 置入既有示意场地，绝不分别压缩 x/z。外立面参照照片缩放到真实长宽，场地仍标注示意。B1 为 A～D/5～7 局部地下室，图纸朝向与上层不同，必须旋转映射。地下室原图有池底 -3.8m、泵房 -5.6m，不能铺成整层停车库。

本机基准：Firefox，当前 Mac，渲染缓冲 1556×1011，外观/晴天/自动环绕，10秒均值 41.2 绘制帧/s、CPU 1.02ms、171次绘制、157113三角形；GPU计时不可用。旧 GLB 9,732,436 bytes，184 meshes / 167066 triangles / 9,574,176 geometry bytes（含隐藏系统）。目标：同窗口连续环绕≥30绘制帧/s，CPU提交≤8ms，结构内存≤12MiB、原模型外观绘制次数增量≤30。触控与低端手机未实测前不宣称性能通过。

图纸核对：2～6层共同核心筒/货梯/前室/水电井，三处分区；首层停车、分拣及设备用房；七层 Q～M/2～6 上人屋面；地下室消防水池与泵房。货梯“后装”只显示预留井位，不假装已装设备。不存在施工证据的重复货架与示意消防管线去除。
