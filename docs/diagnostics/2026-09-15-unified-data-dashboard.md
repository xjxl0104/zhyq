# 数据看板与监控大屏合并

## 用户确认的展示方式

保留一个「数据看板」入口，默认使用普通看板，提供一键全屏。

## 整合范围

- 保留原数据看板的财务指标、应收/实收趋势、房源分布、经营收入来源、合同执行、设备状态、工单分类。
- 合入原监控大屏的出租率、在租房间、进行中工单、实时告警和招商转化；相同图表和概览数据共用原看板。
- 告警每 15 秒更新，其他数据每分钟更新。手动刷新同时刷新两部分；离开 KeepAlive 页面时停止轮询，返回时刷新。
- 招商阶段改为使用现有 `/crm/analysis/funnel` 真实统计，移除原大屏按固定比例构造「意向」等数据的做法。
- 告警优先展示待确认事件，回退历史记录时明确标为「最近告警」并展示各条状态。首次加载失败与空数据明确区分，保留可重试入口。
- 全屏使用同一页面和图表，支持按钮退出与浏览器 Esc 退出；图表随容器尺寸变化重算。
- 移除重复菜单和报表入口，更新经营看板快捷入口；旧 `/screen` 跳转 `/data/center`，保留 query/hash，登录要求沿用原路由守卫。
- 删除不再使用的 BigScreen.vue；未修改后台业务逻辑或接口权限。

## 验证

- 新增回归先失败后通过：独有数据合入、历史告警标记、加载失败重试、KeepAlive 轮询起停、全屏状态与 Esc 恢复。
- 前端完整 30 个测试文件 / 116 项通过，`pnpm build` 通过。
- 后端 `mvn -B test-compile` 通过。
- Chromium 检查 1440px、1024px 和全屏展示，旧路由兼容、全屏进入/退出通过，无 JavaScript 页面错误；1024px 看板没有横向溢出。
- 浏览器使用本地 API 测试数据验证布局和交互，没有修改生产业务数据。
