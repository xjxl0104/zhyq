# 全民营销与智慧云仓演示说明

本文用于演示园区后台、园区伙伴端和云仓商家端如何协作。演示数据应放在独立测试环境；本文不提供生产账号、密码或登录令牌。

## 演示前准备

- 打开三个独立窗口：园区后台、园区伙伴端、云仓商家端。建议后台用电脑，两个小程序角色用不同手机或独立浏览器会话。
- 后台入口为「招商 → 全民营销」。需要客户管理、加盟审核、合同、账单、结算、提现等相应权限。
- 伙伴与商家均可使用账号密码注册、登录；已有微信身份可在登录后设置账号密码。注册会建立业务伙伴或云仓档案，不会创建后台管理员。
- 准备明确标注“仅供测试”的资质附件、签署件和收付款凭证。在演示库使用测试资料，实际业务必须使用真实资料与实际资金流水。
- 无外部 ERP 的云仓走“人工导入出库单”模式。完成资质审核、选择人工模式、提交加盟协议并由园区确认上线后，才能承接客户。
- 配好客户评级、云仓成本费率、合同收费标准和佣金规则。按量收费合同报价应覆盖云仓成本与佣金；不要为了展示结果篡改生产规则。

## 给领导演示：四个场景

### 1. 推荐客户，后台收到同一条记录

伙伴端打开「推荐客户」，填写客户与联系人信息、业务需求，选择意向云仓后提交。

后台打开「全民营销 → 客户管理」，按客户名称或手机号搜索。展示推荐伙伴、意向云仓和预锁状态；进入「锁定」，由专员确认有效锁定。根据实际洽谈依据设置客户评级。

可以这样说明：**伙伴提交的推荐直接进入园区客户档案，园区可以核验推荐归属。意向云仓只是推荐人的选择，还需要园区分派。**

### 2. 园区分派，商家承接，伙伴看到进度

后台在客户行点击「分派云仓」，选择已上线的云仓，填写分派原因。

商家端打开「承接客户」，刷新后看到这条客户，点击「确认承接」。再通过「更新服务进度」发布一条适合对外展示的进度。

回到伙伴端「我的客户 → 客户详情」，点击「刷新进度」，展示分派云仓、已承接状态和刚发布的进度。

可以这样说明：**三个入口共享同一份客户归属。园区负责分派，商家确认服务，推荐伙伴能够查看允许公开的进度。内部备注不会自动公开。**

### 3. 合同生效，客户与推荐归属一起变化

主线采用园区签：后台打开「服务合同」，选择已承接客户并起草合同，填写服务类型、起止日期、计费方式、价格、保证金及结算周期。保存草稿、提交审核、审核通过后，上传该云仓的有效签署件并完成线下签署登记。

刷新伙伴端客户详情与商家端客户列表。客户应显示“已签约”，伙伴归属显示“已成交”。已有有效合同的客户不能直接换承接仓或更换推荐归属。

合同状态自动同步；之前人工发布的公开进度文字不会自动改写。签约完成后，可再发布“已完成签署，进入履约准备”等与实际情况一致的新进度。

另一个可选分支是云仓直签：商家端「合同协议 → 起草直签合同」，选择已承接客户，保存条款与签署件后提交；园区在「服务合同」完成备案审核使其生效。

可以这样说明：**合同生效会同步客户状态、推荐归属和相关财务记录。园区签与云仓直签分别按自己的收款关系处理。**

### 4. 真实业务凭据推动对账、结算和提现

后台「计佣订单」下载模板，按真实出库记录填报并导入。商家端「出库单」可查看本云仓订单。系统按合同单价和数量计算服务费，再按评级和伙伴关系计算佣金。

上面这条计费、计佣主线适用于园区签合同。云仓直签的人工出库记录用于展示运营数量，不产生园区代收服务费或出库佣金；平台费按实际到账另行登记，不能把客户付给云仓的营业额记成园区收入。

后台「服务费账单」生成指定合同、账期的账单；商家核对明细并确认。财务收到客户款项后，上传到账凭证，填写流水号和实际到账金额。

后台「云仓结算」依据已收款账单生成云仓应付；商家核对并确认，财务在线下实际付款后登记流水与凭证。

伙伴提交收款资料，由园区在「伙伴管理」人工审核。佣金达到可结算条件后，后台「佣金结算」执行结算，伙伴端「收益 → 提现」申请；后台「提现审核」审核并登记实际打款结果，伙伴端查看记录。

可以这样说明：**订单、账单、佣金和提现记录可以串联查询。财务确认实际收付款并留存凭证后，系统推进对应状态。**

## 完整业务操作顺序

| 环节 | 操作入口 | 结果或约束 |
| --- | --- | --- |
| 伙伴注册 | 伙伴端登录页 | 后台「伙伴管理」出现业务记录 |
| 云仓申请 | 商家端「加盟申请」 | 后台「加盟申请」可审核资料 |
| 云仓上线 | 后台资质审核、人工订单模式、加盟协议确认 | 人工模式不会把 ERP 状态标为已联通 |
| 推荐与归属确认 | 伙伴端推荐；后台「客户管理 → 锁定」 | 预锁经专员确认后成为有效锁定 |
| 分派与承接 | 后台「客户管理」；商家端「承接客户」 | 商家只能处理分派给自己的客户 |
| 公开进度 | 后台或已承接商家发布 | 伙伴刷新客户详情可见 |
| 园区签合同 | 后台「服务合同」 | 草稿 → 待审核 → 待签署 → 生效 |
| 云仓直签合同 | 商家端「合同协议」；后台备案 | 签署件齐全后提交，园区审核生效 |
| 人工出库导入 | 后台「计佣订单」 | 园区签根据合同计费；直签仅记运营数量，不生成出库佣金；重复单号不会重复入账 |
| 服务费收款 | 后台「服务费账单」；商家核对 | 核对确认后登记实际到账及凭证 |
| 云仓结算 | 后台「云仓结算」；商家确认 | 以已收款且未进入其他批次的账单生成应付 |
| 收款资料审核 | 伙伴端「我的」；后台「伙伴管理」 | 保存资料进入待审核，不等同于已完成实名核验 |
| 佣金与提现 | 后台「佣金结算」「提现审核」；伙伴端「收益」「提现」 | 冻结、结算、提现各有独立条件；不能跳过收款资料审核 |
| 查询操作依据 | 后台「审计日志」 | 可追查分派、审核和财务登记等操作 |

## 现场容易遇到的情况

- **查不到推荐客户：**先确认当前角色、客户名称和后台项目筛选，再刷新。尚无园区归属的新档案显示“待分配园区”，不会冒充已归属当前园区；不要通过重复推荐制造第二条档案。
- **商家没有可承接客户：**先由园区分派。只选意向仓或只配置 ERP 货主映射，不会授予客户权限。
- **无法签署生效：**检查云仓是否上线、商家是否已承接、客户报备是否已确认、合同日期与价格是否有效、附件是否属于该云仓。
- **直签不能提交：**先编辑草稿，上传签署件再提交审核。直签草稿不能直接备案生效。
- **账单或结算不能确认：**查看是否存在争议、冻结或当前状态已变化；先处理问题，再刷新重试。
- **收益不等于可提现余额：**冻结佣金要满足解冻条件，可结算佣金还需要后台结算；提现还要求已审核的收款资料及有效余额。
- **客户结束服务：**终止或到期后，仅当该客户没有其他有效服务合同时，才恢复跟进状态并释放成交锁。不能用标记流失代替有效合同终止。
- **同一按钮重复点击：**状态更新和关键单据有幂等或冲突检查；重复操作不应重复产生订单、佣金或付款记录。

## 演示时必须说明的边界

1. **外部 ERP 尚未接入时，本链路依靠人工 Excel 导入。**本次演示不能称为 ERP 自动推单或自动对账联通。
2. **收款资料是人工审核。**系统可以保存、保护和审核资料，但没有因此自动完成公安身份核验、银行四要素核验或微信实名认证。
3. **收付款是线下发生后登记。**上传凭证、记录流水号和变更状态不会自动向微信钱包或银行卡转账；不要把“标记已打款”说成系统已经调用了微信支付。
4. **签署件上传不是电子签平台签署。**当前流程记录线下已签文件及园区审核；电子签能力以实际接入为准。
5. **真机微信登录需单独验收。**账号密码登录和 H5 演示通过，不代表微信小程序已完成真实 AppID、服务器域名、手机号权限及发布环境验证。
6. **演示金额只能来自明确测试场景或真实业务。**测试库可以设置明确的验收费率和测试日期，不能把测试佣金、模拟凭证展示为线上实际收入或实际付款。

## 本地验收入口

当前开发验收环境使用桌面后台 `http://127.0.0.1:5286/`、小程序 H5 `http://127.0.0.1:5286/mp/` 和隔离后端 `http://127.0.0.1:19092/api`。这些地址仅用于本机验收，不是生产地址。

本地自动化流程使用专门创建的测试伙伴、云仓、客户和订单。登录状态文件仅供验收程序读取，权限应为 `0600`；不得随截图、文档或代码提交分享。
