# 小程序超级管理员账号管理

## 行为

- 伙伴端“我的 → 账号管理”仅对正常状态且有专用超级管理员授权的伙伴显示。
- 管理伙伴、云仓商家两类账号：搜索与分页、新增账号密码账号、停用/恢复登录、删除空账号；支持修改任意伙伴的本人邀请码。
- 业务岗位 P1–P4 与管理权限分离，管理权限不授予园区后台权限，不改变定价、分佣或商家审核。
- 新增伙伴默认 P1，可选上级邀请码；新增商家仍需完成资质审核。不代填用户协议接受时间，不将填写的电话标记为已验证。
- 邀请码为现有的 8 位字母或 2–9 数字格式，大小写归一、唯一性和并发旧值校验。改码不改变已绑定的上下级关系，原分享链接/码图需重新生成。
- 删除有业务依赖的账号会拒绝；可以停用登录保留历史。不能在此界面停用或删除超级管理员。账号操作均必填原因；管理审计失败会回滚。
- 停用同时阻止密码与微信登录，每个 JWT 请求读取当前登录控制状态。恢复后旧 token 仍失效，需要重新登录。

## 权限存储与部署

V85 只新增 `crm_marketing_account_control` 表，不自动将固定 ID、手机号或姓名提权。授权须在实际环境核对身份后单独执行，并记入 `sys_audit`。公共资料 DTO 不包含管理权限字段，也没有公开提权接口。

本次授权对象由用户指定为王钰淞。生产执行前应再次核验 `crm_promoter` 的 ID、姓名、邀请码、未删除和正常状态，事务写入专用授权与审计；不修改其原有登录密码、微信身份、岗位和团队。

小程序版本 1.9.0，沿用现有 AppID `wxc01f4ad2297319a0`。后端按 feature → test → main 流程发布阿里云；小程序构建上传开发版后，正式版生效仍受微信审核/发布流程约束。
