# 提现代申请核对与两端指定审批

## 行为

- 后台代申请按姓名、手机号或邀请码搜索伙伴，显示伙伴编号、称号、手机号、邀请码、收款户名/银行/尾号、账户审核状态、余额、冻结金额和处理中申请。
- 提交前核对伙伴与金额；账户未核验、非开放日期、已有处理中申请或审批流程不可用时明确阻止提交。
- 后台提现审核和审批中心展示申请时的收款快照、金额及审批记录；只有当前流程实际指定人员可以办理提现，管理员不能替代指定人。
- 小程序「我的」按服务端能力显示「提现审批」，审批意见必填并二次确认；申请人可以查看自己的审批历史，不能读取他人单据。
- 审批身份采用管理员明确核验的后台员工用户名与伙伴 ID 绑定。仅限单次提现审批调用，不签发员工 token，不按姓名、手机号、P4 或营销超管身份推断权限。
- 提现日期文案读取后端规则；缺失规则时引导查看提现页，不承诺随时可提。

## 管理入口

1. 在现有审批流程维护页启用「伙伴提现审批流」，将节点审批类型设为用户并选定实际审批员工。
2. 后台提现审核页「提现审批人设置」选择同一后台员工及其已核验的小程序伙伴身份。
3. 双身份配置仅管理员可改，普通营销参数编辑不能修改这两个配置。
4. 已生成的审批任务保留原节点与审批人快照；变更配置不得冒用原审批身份。

## 资金与操作边界

提现申请必须使用已经审核的收款账户，保存申请时账户快照。批准仅进入待打款状态，财务付款仍使用原有凭证与幂等处理。当前开放日期规则保留。真实金额调整、收款账户核验与付款不得通过测试样例或伪造资料替代。
