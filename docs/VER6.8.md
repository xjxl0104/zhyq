# ver6.8 发布说明

## 版本关系

- `ver6.8` 直接继承已验收的 `ver6.7`。
- `ver6.7` 可追溯到远端 `ver6.6` 精确提交 `a5b419827605efcc76fcc46fc4d87f3444aeb5b0`。

## 毛玻璃表面

- 新增 `GlassSurface`，提供 `upload` 与 `card` 两个视觉变体。
- 装饰光团和遮罩不接收指针事件、不进入可访问性树，真实业务控件保持在内容层。
- 上传变体使用 18 秒、仅改变 transform 的环境光旋转；卡片变体保持静态渐变，避免同时运行大量循环动画。
- `prefers-reduced-motion: reduce` 下停止旋转；不支持 `backdrop-filter` 时使用不透明浅色回退。
- 视觉方向参考用户提供、标注为 “From Uiverse.io by monkey_8812” 的示例，并按本项目亮色企业后台重新设计。

## 上传入口覆盖

以下入口保留原 `el-upload`、鉴权、校验、文件列表、解析、错误处理和提交逻辑，仅增加视觉容器：

1. 通用附件上传。
2. 自动售货机 Excel 导入。
3. 应收明细 Excel 导入。
4. 责任单位 Excel 导入。
5. 全局建议反馈截图。
6. 我的建议截图与普通附件。

## 展示卡片覆盖

- 工作台：顶部待办指标与经营概览卡。
- 应用中心：“我的常用”与“全部应用”两个展示分区。

表格、查询栏、编辑表单、预警/待办/快捷入口和其他高密度统计卡不应用毛玻璃。

## 兼容性

- 无后端、数据库、权限、路由或业务数据流变更。
- 文件状态、错误文案和成功反馈仍由原业务组件提供，毛玻璃不是状态的唯一提示。

## 导航与品牌动效增强

- 参考 React Bits 首页导航，将玻璃高亮改为跟随悬停与键盘焦点，离开后回到当前菜单；支持菜单展开、滚动和尺寸变化后的重新定位。
- 点击反馈增强为 12 个紫色、靛蓝和琥珀色粒子，展开状态的爆发点位于菜单宽度的 76%，避开文字中心；收起状态居中。
- 玻璃高亮与粒子滤镜分层，保留高亮边框和内部反光；降低小粒子的模糊半径，避免被透明度阈值滤掉。
- 删除左上角建筑 Logo，标题改为“澳乐智慧云仓系统”，参考 React Bits Stroke Text 实现逐字描边后从左向右填色；首次出现及悬停时播放。
- 动效使用 Vue、CSS 和 SVG，不新增动画依赖；减少动态效果偏好下保持静态，组件卸载时清理监听器与定时器。

参考：[React Bits 导航](https://reactbits.dev/)、[Stroke Text](https://reactbits.dev/text-animations/stroke-text)。
