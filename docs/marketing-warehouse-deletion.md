# 加盟云仓删除与维护记录

- 后台加盟云仓列表提供管理员“删除”按钮，必须填写 1–500 字原因。确认后在同一事务内立即逻辑删除，从业务列表移除并停用关联账号、登录绑定、ERP 凭证及保护名单，不再设置 7 天冻结期，也不再提供撤销删除接口。
- 未结束的服务合同、关联客户仍有未结束合同或启用中的云山映射会阻止删除。无未结束合同的关联客户退回待分派；历史合同、订单、财务档案及维护记录保留。
- 旧版已处于“冻结待删除”的记录不再等待原定期限。兼容任务每分钟重新检查业务限制并归档，每条独立事务；管理员也可在列表中立即删除。未通过检查的记录保留并记录失败日志。云仓行锁及条件更新防止重复删除。
- “新增云仓”旁的“加盟云仓维护记录”可查询新增、正式删除和旧版申请、撤销记录，包括操作人、时间、原因和状态变化。删除完成的审计与访问权限停用处于同一事务，失败则整体回滚。
- 小程序超级管理员的云仓账号删除复用同一立即删除服务，提示与后台保持一致。
- 沿用 V87 的删除元数据字段，无需新增迁移；旧迁移文件与历史审计保持不变。

伙伴删除校验已调整：已逻辑删除的线索、客户，及已释放的非成交锁不再阻止删除；已清空客户遗留的定价版本不再阻止删除。有效客户/活锁、成交锁、下级、合同、订单、佣金及提现历史仍受保护。

数据库升级：`V87__warehouse_deletion_grace_period.sql`。正式删除仅从业务列表移除，历史档案与维护审计继续保留。
