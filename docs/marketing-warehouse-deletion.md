# 加盟云仓删除与维护记录

- 后台加盟云仓列表提供管理员“删除”按钮，必须填写 1–500 字原因。提交后状态为“冻结待删除”，立即禁止云仓登录、修改资料、加盟推进及新增承接业务。
- 删除时间由服务端确定为申请时间加 7 天，重复提交不能延长。列表显示删除原因和预计删除时间。
- 冻结期间管理员可填写原因撤销删除，恢复此前加盟状态；到期后不能撤销。每分钟任务检查一次，服务停机期间不提前删除，重启后补处理。多实例通过云仓行锁和条件更新避免重复完成。
- 未结束的服务合同及待承接/在服客户须先处理或转移。已有历史订单和财务记录不被物理删除；正式删除使用逻辑删除，清除登录绑定、停用 ERP 凭证及保护名单。
- “新增云仓”旁的“加盟云仓维护记录”可按名称/编码查询新增、申请删除、撤销及正式删除，包括操作人、时间、原因、状态变化及删除期限；已删除云仓的记录保留。关键维护审计失败会回滚业务操作。旧云仓缺失的新增审计补录原创建时间并标注“历史新增记录补录”。
- 小程序超级管理员的云仓账号删除复用相同 7 天流程，不能绕过冻结期。

伙伴删除校验已调整：已逻辑删除的线索、客户，及已释放的非成交锁不再阻止删除；已清空客户遗留的定价版本不再阻止删除。有效客户/活锁、成交锁、下级、合同、订单、佣金及提现历史仍受保护。

数据库升级：`V87__warehouse_deletion_grace_period.sql`。正式删除仅从业务列表移除，历史档案与维护审计继续保留。
