# 资料管理 · 分类架构与规则说明

> 种子数据来源:`docs/archive/gen_seed.py`(生成 `V121__archive_seed.sql` 与单测用 `taxonomy.json`)。上线后分类与关键词规则在系统「资料管理 › 分类与规则」里维护,不再改本文件的种子。

## 设计思路

- **两层分类**:门类(2 位,如 `03`)+ 子类(`03.04`)。按「业务领域」归类,「文档类型」(制度规程/合同协议/证照证明/台账清单/记录表单/通知账单/方案报告/图纸图片/票据凭证/函件申请/其他)作为另一个筛选维度——同一份「消防安全管理制度」按领域进 `08.01 消防安全制度与协议`,类型标「制度规程」。
- **档号**:`子类编码-年度-流水号`,如 `03.04-2026-0001`;档号一经生成不变,删除后不复用。
- **规范化名称**:`主题-期间-版本`,如 `物业服务合同-五矿-2026-盖章版`;去掉「微信图片」「副本」「(1)」「1、」等杂乱字样;识别不到的部分省略。
- **密级**:公开 / 内部 / 机密,按子类给默认值,命中关键词(身份证、车牌、人脸、银行、账户信息…)自动上调。本期只做标注与筛选,不改变账号权限。
- **自动归类**:读取文件名、所在文件夹、正文(PDF 文本层 / Word / Excel / 文本),按关键词规则打分(文件名 ×3,文件夹 ×1 且封顶,正文 ×1),分数最高的子类胜出;没有把握归「99.01 待归类」。扫描件/图片没有文本层,只能依据文件名与文件夹。
- **保管期限**:按用户决定本期不设。
